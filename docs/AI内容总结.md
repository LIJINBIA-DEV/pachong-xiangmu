# AI 内容总结

## 设置入口

数据管理页面右上角点击“AI 设置”。统一配置：

- 接口地址（Base URL 或完整 chat/completions 地址）。
- 服务商提供的模型名称／ID，自由填写，不限定模型品牌。
- API Key。保存后各采集任务共用，不需要每次生成时重新填写。
- 默认分析范围、最多分析记录数，以及是否包含已保存评论。

当前支持 Chat Completions 兼容接口及 JSON 输出。基础地址会自动补充 `/chat/completions`；接口使用 HTTPS，本机服务也可使用回环 HTTP 地址。原生非兼容接口需要通过兼容网关接入。

Key 加密保存在后台数据目录下的隐藏 `.ai-settings/` 中，不回显，不保存在浏览器或总结报告中。Key 留空表示保留当前配置；更换接口地址时旧 Key 不会沿用，应填写新接口对应的 Key。“清除已配置的 Key”可明确清空。

后台可通过 AI_BASE_URL、AI_MODEL、AI_API_KEY 初始化；兼容原有 DEEPSEEK_API_KEY。网页保存的配置优先，明确清空不会恢复环境变量中的 Key。Mac 启动器支持从原有私有设置文件加载这些环境变量。无需向聊天窗口提供密钥。

## 生成与查看

选择采集任务，点击任务旁的“AI 内容总结”。窗口只显示生成操作、进度和报告。总结方式自动跟随任务：普通主题归纳讨论内容、观点与分歧；有限定评价的任务进一步分析有原文依据的态度。旧任务标记继续兼容。

点击“生成内容总结”或“重新生成总结”才会向所配置的模型接口发送所选文字。保存设置不会调用模型。进行中的总结固定使用启动时的配置，更改设置仅影响下一次生成。关闭总结窗口不会中断任务。

报告包含总体归纳、讨论点／评价态度、逐帖概述、逐字原文依据及已采集的原帖链接，可下载 Markdown。模型生成的链接不会直接采用，链接由本机关联。旧报告及采集、人工审核数据不改写。

## 范围和验证

最多分析 500 条记录；同一帖子命中不同主题时分别分析。仅纳入所选状态，排除记录不参与。标题最多 500 字符，正文最多 8000 字符；启用评论时每帖取前 10 条唯一评论、每条最多 400 字符。报告说明截取与遗漏数量，不将少量样本解释为整体公众意见。

模型引用必须逐字出现在对应原文中，引用帖子编号必须存在。校验失败保留上次成功报告。切换模型不保证任意服务都支持所需 JSON 结构；接口错误不会覆盖旧报告。

接口结构参考：[Chat Completions 接口说明](https://api-docs.deepseek.com/)；[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。配置入口及请求适配不限定该服务商。
