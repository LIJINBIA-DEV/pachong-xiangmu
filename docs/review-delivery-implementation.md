# 审核结果交付：本地实施与验收记录

日期：2026-10-12  
范围：按审核结果打包导出规格实施本地项目；没有更新或重启 Spark，没有修改 Jev 中转、Qwen 设置或原有 CMD。

## 已完成

- 人工审核选择器只显示采集主 Excel，隐藏同轮语义结果文件；后台验证旧选择对应的同轮主文件和任务关联，缺主文件时提示。
- 配置页仅显示 Excel；新任务使用 Excel，历史其他格式数据仍可通过数据管理功能读取，运行中任务不受配置显示变化影响。
- 导出按钮准备 ZIP，然后交给浏览器原生下载。包内有审核结果 Excel、保留帖的合格原始图片、图片对应表和导出说明。
- 九个既有交付字段不变；人工标记、原始数据和识别缓存不被导出修改。旧的仅 Excel 导出接口保留兼容，新页面使用 ZIP 任务接口。
- 根据任务关联包含补采轮次；重复引用共用原图。不合格及未标记图片不进入结果包，也不当作缺图计数。
- 合格图片缺失、无可导出合格图片、待审核帖子明确报告；没有保留帖或无法完成归档时失败，不返回伪成功空包。
- 独立准备任务最多一个，同时最多保留三个可下载结果包；页面提供其他临时包的下载和移除入口。
- 使用 ZIP64、分块图片读写与磁盘临时归档，不把全部 ZIP 放入后端内存或浏览器 Blob。
- 取消准备和下载异常都释放对应资源；下载中不会移除正在读取的包。一个小时不活动的完成任务过期，由后台每分钟和 API 操作触发清理；只清理本功能拥有的临时文件。
- 后端重启不会恢复导出任务句柄，旧下载链接失效；重新发起导出即可。历史遗留临时包在本功能再次识别相应数据根目录后进入清理范围。

## 验收证据

### 接口及前端测试

- 本次功能及关联回归测试：56 项通过，覆盖实际 ZIP、图片对应、人工标记保持、重复引用、缺图、零保留帖、长中文名解压、任务关联、下载发送中断、取消、过期、容量及磁盘不足模拟。
- 前端测试：33 项通过，覆盖配置持久化、历史格式、文件选择、已有审核保存和结论行为。
- TypeScript 与生产构建通过。
- 在主要改动完成时运行了一次整个测试目录：832 项通过、1 项跳过、4 项失败。失败为 Unix shell/grep 依赖的媒体及账号旧测试，以及被当前已有 CMD 会话占用拦截的启动器测试。本次未为全套通过去关闭原 CMD 或修改这些无关模块。后续修复又运行了上述相关测试。

### 实际页面与下载

- 在独立本地验收服务、合成测试数据上操作真实页面，没有对用户的已有采集数据进行导出或改判。
- 人工审核下拉菜单只显示主 Excel；实际展开配置菜单，仅有 Excel 一项。
- 点击“导出 Excel＋合格图片”，浏览器实际保存 ZIP；再从下载目录读取并核对包内内容。
- 验收样本：保留 2 帖、打包 1 张原图、待审核 1 帖、合格图片缺失 1 张、无可导出合格图片 1 帖，页面和包内结果一致。
- 原图内容与源文件一致；审核结果主工作表仍为九列；图片对应表记录成功路径和缺失原因。
- 截图及验收下载包位于本地验收产物目录，全部使用独立测试数据。

### 较大归档资源实测

- 独立生成 40 张图片，总原图约 137.77 MB，通过真实 HTTP 准备和分块下载约 137.78 MB 的 ZIP。
- 本机样本：准备约 0.27 秒，准备及流式下载合计约 0.61 秒。
- 测试进程工作集由约 88.57 MB 增至约 92.23 MB，增量约 3.65 MB；证明此样本没有将整个约 138 MB 的结果包累积到进程内存。
- 下载后移除临时包，核对临时 ZIP 已删除；合成负载数据也只在受控测试目录使用。
- 上述为本机缓存磁盘上的合成样本，不是 Spark 性能指标，也不是 756 GB 完整规模验证。数值及测试范围记录在资源验收 JSON 中。
