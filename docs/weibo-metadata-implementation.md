# 微博公开账号、性别与地点：实施及验收记录

日期：2026-10-14。实现范围为本地新采集的 Excel 工作台链路。未发布到 Spark，未补采历史记录。

部署更新（2026-10-15）：用户随后授权发布，现已部署到 Spark。候选镜像 24 项测试、线上健康/API/实际导出与数据保护核对均通过，详见 `spark-deployment-20261012.md` 的 2026-10-15 记录。下文保留本地实施时的验收边界。

## 已实现

- 保存公开昵称、字符串账号 ID、去除跟踪参数的微博主页链接、完整认证说明，以及公开资料中的性别。保留原有匿名账号关联与账号审核证据。
- 平台性别 m/f/n 显示男/女/未知；缺失、无效类型及查询失败显示未获取，不进行推断。
- 地点采用微博明确附带的 annotations.place 或有效 geo 坐标；没有定位时回退到该帖 region_name。独立保留 IP 属地，明确标记地点来源。正文、转发原帖及作者地区不参与回退。
- 缺失资料通过现有客户端有界补查。详情按帖子、作者资料按账号在任务内复用，并发查询合并；失败不会丢弃帖子。已有完整正文不会被短详情覆盖。
- 同帖跨搜索行先缺失后补全、或先完整后缺失，已取得的元信息在主 Excel、语义结果和检查点中保持一致。搜索行、模型结论、评论及人工标记保持原有关联。
- 数据管理和人工审核展示统一元信息。长认证说明支持滚动，窄账号栏的审核按钮自动换行。
- 审核结果从九列扩展为十六列：原发布地点更名为地点（定位优先），末尾追加账号昵称、账号 ID、账号主页链接、认证说明、性别、IP 属地、地点来源。直接 Excel 与 ZIP 使用同一映射；字符串不作为公式保存。
- 旧文件可正常读取、审核和导出，不触发补采。其他平台的显式地点标记为帖子定位，不套用微博 IP 回退。

## 真实平台证据及限制

浏览器有限查看两条公开微博（5351081049588843、5351172752019615）的页面内 render_data，均观察到 user.gender=m、公开主页链接；帖子 region_name 分别为“发布于 河北”“发布于 上海”。真实样本证据见 `.scratch/weibo-post-metadata/live-browser-evidence.json`，没有保存 Cookie 或主页链接中的访客跟踪参数。

直接 HTTP 探测被转到访客登录页，本地没有可复用登录会话。因此：真实公开字段映射已部分验证，但本次没有完成带真实采集会话的补查端到端实测；两条样本均无附带定位，annotations/geo 分支只完成构造响应验收，不能声称已取得真实定位样本或每条微博一定返回这些信息。
