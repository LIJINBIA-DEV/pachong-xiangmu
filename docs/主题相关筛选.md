# 语义筛选与数量说明

配置页统一填写“采集主题”，每张卡片独立搜索。打开“语义筛选”后，结合标题、正文和已采集评论判断主题相关性；需要限定评价时，再打开“只关注某种评价”，填写希望关注的评价或看法。

不限制评价对象类别，不要求帖子有图片。人物、动物、食品、服务、事件及抽象概念都可以作为采集对象。评价判断需要原文支持评价确实描述指定对象，不能仅凭两个词同时出现通过；证据不足进入待复核，不计入采集目标。评论和图片数量不计入帖子目标。

人工审核以整帖结论为准。没有配图、图片未下载、旧图片识别结果或图片标记都不会自动决定帖子是否保留。图片仅用于预览和可选下载；审核结果包导出人工采用的帖子，并附上已下载配图，纯文字帖子也可导出。

历史数据文件与审核标记保留。旧场所分类和图片结论仅作为历史记录，不再充当人工采用的限制；历史已排除的帖子不会因此自动改成已保留，需要重新审核或重新采集。当前规则仍保留原文依据、主题相关性、重复内容和已有账号排除规则。

网页新任务从第 1 页开始搜索；界面不再显示起始页。后台的断点续采仍保留。

## Jev Key 保存

在配置页输入 TypeSafe API Key 后点击“保存 Key”。测试通过或带新 Key 开始采集时也会保存。已配置时显示保存状态，不回显完整密钥；后续输入框留空即可复用。刷新页面、关闭浏览器或重启同一台电脑上的项目后仍可继续使用。

Key 加密保存在当前后端的数据目录中，与 AI 总结 Key 分开管理。采集、补采、连接测试和代理测试复用这份配置。输入新 Key 并保存即可更换，点击“清除已保存 Key”后下次需要重新配置；未配置过时仍兼容 TYPESAFE_API_KEY 环境变量，主动清除后不会自动恢复环境变量中的旧 Key。
