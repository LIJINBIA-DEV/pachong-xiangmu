# 搜索关键词与 TXT 导入

配置页使用一个可滚动的多行输入框。每个非空行是一次搜索，行内用空格隔开关键词；输入框不会自动生成其他组合。多余空格、制表符和全角空格会统一为空格，空行会跳过。

```text
可爱 公园
可爱 雕塑
可爱 雕像
萌 公园
萌 雕塑
萌 雕像
```

上例是 6 次搜索。需要更多关键词时直接写在同一行，例如 `萌 公园 雕像`，仍然是一次搜索。请不要用逗号、顿号或分号代替空格；每行至少两个关键词。

“导入 TXT”将文件中的行追加到输入框末尾，保留顺序和重复行。支持 UTF-8、记事本 UTF-16 和 GBK，单个文件不超过 1 MB，单次任务最多 10000 行。内容超过输入框高度或宽度时可滚动查看。

原来的 `关键词一.txt` 与 `关键词二.txt` 已一次性合并为上一级目录的 `关键词组合.txt`，共 189 行，原文件保留。后续请编辑和导入 `关键词组合.txt`，不再分别导入旧的两组列表。

浏览器中已保存的旧两组标签会迁移成逐行组合，未提交的标签草稿也会保留。新的行输入会保存到浏览器；Cookies 和 API Key 不会保存到浏览器配置中。
