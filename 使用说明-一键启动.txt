MediaCrawler Windows 一键启动包

适用：Windows 10/11 64 位 Intel/AMD 电脑。首次运行需要联网。

1. 把整个 ZIP 解压到一个可写的本地目录，不要直接在压缩软件中双击运行。
2. 双击“一键启动.cmd”。无需先安装 Python、Node.js，也无需手动开启 Chrome 调试端口。
3. 首次运行会下载项目专用的 uv、Python 3.11、Node.js，并安装 Python、前端依赖。
   优先使用已安装的 Chrome/Edge；不可用时下载独立 Chromium。请耐心等待。
   工具存放在本目录的 .runtime 和 .venv，不修改系统 PATH，不需要管理员权限。
4. 页面打开后，登录环境选“本机版”，登录方式选“扫码登录”。
   点击“开始爬虫”后，在弹出的独立采集浏览器里扫码并按平台提示确认。
5. 使用文本筛选、图片识别前，在配置页填写自己的 Jev、硅基流动 API Key。
   此包不附带他人的密钥、Cookie、旧采集数据、人工审核记录或本地模型。
6. 运行期间保留 CMD 窗口。关闭窗口或按 Ctrl+C，项目会停止。

第二次启动会复用已安装环境和登录状态。登录过期、验证码仍需本人处理。
下载安装成功不代表微博一定允许采集；平台验证、账号权限和 API 网络可达性取决于使用者环境。
本包不会启动原作者电脑上的 Jev 中转，也不会连接或修改 Spark。

遇到错误：
- 安装中断：检查网络后重新双击；已完成的步骤会复用。
- GitHub/nodejs.org/Python 软件源不可访问：解决本机网络访问后重试，不要关闭证书校验。
- Chromium 下载超过 10 分钟会停止并提示。可改善网络后重试，或先安装官方 Chrome/Edge 再启动。
- 页面端口占用：先查看是否已有本项目窗口；不要随意结束别的服务。
- 文件移动后环境失效：启动器会保留旧 .venv 为 .venv.previous-日期，并重新安装。
- 日志：artifacts\setup 下是环境安装日志，artifacts\startup 下是服务日志。
- 依赖损坏：在此目录终端执行 .\一键启动.cmd -Repair，重新检查安装。
- 仅安装不启动：.\一键启动.cmd -SetupOnly
- 自定义端口：.\一键启动.cmd -ApiPort 18581 -WebPort 15173

数据与隐私：
新采集数据、审核记录与模型 API 设置保存在 data；浏览器登录状态保存在 browser_data。
以后转发此程序时，不要把这些目录、.env 文件和安装日志一起转发。
代码中的 model（单数）、cache 是程序模块，不能删除。

首次启动时请阅读并自行确认项目许可说明。原项目 LICENSE 随包保留。
